# AI Architecture Preview

An installer-free, project-local preview of eleven small workflows for working with an AI assistant. It is guidance and a few portable templates, not an agent runtime, policy engine, permission system, or measured performance claim.

Start with [INSTALL.md](INSTALL.md), choose only the module relevant to the work, and see [COVERAGE.md](COVERAGE.md) for the map. The continuity module includes a Python 3.11+ stdlib journal and a deterministic recovery fixture. Everything else is Markdown guidance.

The preview is intentionally separate from the parent candidate's installer. It does not use `kit.py`, discover a home directory, alter user settings, or activate native integrations.

## Limits and follow-up

This is a local preview. Native loading and macOS/Windows validation are follow-up work, not requirements to use these files manually. Before public release, complete [RELEASE.md](RELEASE.md), including the required approval for the final public name and push.
