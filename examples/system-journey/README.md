# Deterministic system journey

`run.py` is an authored fixture, not an AI-performance transcript. It passes explicit
availability to the report-only router, writes a bounded brief and fixture result,
performs an independent deterministic check, then records a safe data-only Next in a
temporary local journal. It also proves negative routes for a no-port family
and a pending job. It does not execute Next text, discover providers, call a network,
install anything, or exercise a native harness.

Run from the collection root: `python3 -B examples/system-journey/run.py`.
