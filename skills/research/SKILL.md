# Research
## Objective
Answer a narrow question with traceable sources rather than a confident unsupported summary.
## Steps
1. State the question, intended decision, time boundary, and inclusion rule.
2. Collect primary or authoritative sources where available; preserve URLs, dates, and quoted claims.
3. Separate direct evidence from inference and list material unknowns.
4. Cross-check consequential numbers or quotations against their source.
5. Use [source-note.md](source-note.md) and return a bounded conclusion.
## Output and done check
Done means each consequential claim has a source or is visibly labeled inference/unknown.
## Failure handling
If reliable sources conflict or cannot be reached, report that limitation; do not fill the gap with plausible detail.
## Worked example
Record an API deprecation date with its official announcement URL and access date, then note any unverified migration implications separately.
