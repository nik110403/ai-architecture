# OpenCode adapter

The preparation review retrieved the official [OpenCode skills documentation](https://opencode.ai/docs/skills/) on 2026-10-14. It says OpenCode accepts project-local `.opencode/skills`, `.claude/skills`, and `.agents/skills`, walking from the current directory to the worktree. This is a supplied documentation observation, not a native-loading test or a claim that the page was re-fetched for this release.

For selective adoption, copy all of one `skills/<name>` directory into project-local `.opencode/skills/<name>`, including assets. Refuse an existing destination; inspect and merge manually. The other documented locations are alternatives, not instructions to install duplicate copies. See [INSTALL](../INSTALL.md) for the copy example and checks. Do not overwrite settings, rules or project instructions. Adapt role contracts and command bodies manually to OpenCode's native configuration; Claude metadata does not create OpenCode agents or commands. No global settings change or universal native agent import is proposed.
