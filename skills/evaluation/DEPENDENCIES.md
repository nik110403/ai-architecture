# Selective dependency bundle

Copy `SKILL.md`, `measurement.md`, `receipt-report.md`, `scripts/receipt_report.py`, and
`fixtures/` for the portable offline receipt-accounting demonstration. It uses only the
Python 3 standard library, reads only explicit `--input` JSONL paths in caller order,
and writes no files. Fixtures are authored examples, not telemetry or evidence of model
performance.
